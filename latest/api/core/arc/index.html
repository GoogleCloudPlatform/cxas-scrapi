    Arc¶

    Arc is the Python client for Arc, the AI assistant built into the CX Agent Studio console. It drives an assistant session on an app the way the console does, over the public v1beta REST API: streamed turns (StreamChatAiAssistant), confirmation-card answers, clarification option panels, client-managed long-running operations (evaluation runs are polled and the session is resumed automatically), session CRUD and session artifacts.

    Each turn returns a TurnStreamEvents aggregate that you can render as markdown or inspect field by field. Confirmation cards are answered by a ConfirmationPolicy (manual, click, mixed, scripted) or explicitly with send_confirmation_response. The cxas arc CLI (reference) is a thin wrapper around this class.

    Quick Example¶

    from cxas_scrapi.core.arc import Arc
from cxas_scrapi.utils.arc_confirmation_policy import make_policy

with Arc(app_name="projects/my-project/locations/us/apps/my-app") as arc:
    session_id = "arc-sdk-demo"

    # Ask a question; cards stay pending with the default manual policy.
    events = arc.chat(
        session_id, "What does this app do? Summarize its agents and tools."
    )
    print(events.format_markdown())

    # Build something, clicking through confirmation cards while declining destructive tools.
    events = arc.chat(
        session_id,
        "Add a guardrail that blocks requests for medical advice.",
        confirmation_policy=make_policy("click", deny_tools=("*delete*",)),
        timeout_seconds=1800,
    )
    print(events.text)
    for action in events.confirmation_actions:
        print(action.tool, action.action, "typed" if action.typed else "clicked")

    # Anything still waiting for a human decision?
    for card in events.pending_confirmation_requests:
        print(card.confirmation_id, card.tool, card.context)
        # e.g. arc.send_confirmation_response(session_id, card.confirmation_id, confirmed=True)

    # Artifacts recorded on the session (gcsUri pointers), e.g. an exported bundle.
    for artifact in arc.session_artifacts(session_id):
        print(artifact.get("displayName"), artifact.get("gcsUri"))

    Errors surface as ArcApiError (HTTP status and decoded message), ArcStreamTimeout (idle stream or turn deadline; .partial holds what streamed so far), or ArcStreamInterrupted (connection lost after exhausting re-attach attempts; .partial holds what streamed so far).

    arc ¶

    Client for the CX Agent Studio AI assistant (Arc).

    Arc is the conversational builder assistant embedded in the CX Agent Studio console. This module drives it the way the console does, over the public v1beta REST API:

    • SessionService.StreamChatAiAssistant (server streaming) for turns, confirmation-card answers and client-managed LRO resumption;
    • SessionService.CancelAssistantTurn / GenerateOnboardingSuggestions;
    • AssistantService session CRUD (assistantSessions);
    • google.longrunning.Operations and EvaluationRuns for LRO polling.

    def session_name(self, session_id: str) -> str:
    """Returns the full ``assistantSessions`` resource name."""
    raw = session_id.strip()
    if "assistantSessions/" in raw:
        prefix, _ = raw.split("assistantSessions/", 1)
        prefix = prefix.rstrip("/")
        if prefix:
            own = _APP_PREFIX_RE.match(self.app_name)
            got = _APP_PREFIX_RE.match(prefix)
            if got is None or (
                own is not None and got.groups() != own.groups()
            ):
                raise ValueError(
                    f"Session {session_id!r} does not belong to "
                    f"{self.app_name!r}."
                )
    short = urllib.parse.quote(session_short_id(raw), safe="")
    return f"{self.app_name}/assistantSessions/{short}"

    def stream_turn(
    self,
    session_id: str,
    message: str = "",
    *,
    attached_gcs_uris: Sequence[str] = (),
    confirmation_response: dict[str, Any] | None = None,
    operation_completed_event: dict[str, Any] | None = None,
    resume_from_sequence_number: int | None = None,
    enable_confirmation_cards: bool | None = None,
    enable_client_managed_lro: bool = True,
    timeout_seconds: float = 1800,
    on_event: Callable[[dict[str, Any]], None] | None = None,
    into: TurnStreamEvents | None = None,
) -> TurnStreamEvents:
    """Sends one ``StreamChatAiAssistant`` request and consumes the stream.

    This is the low-level primitive: no confirmation policy and no LRO
    resumption. See :meth:`chat` for the console-equivalent turn loop.

    Args:
        session_id: Short id or full session name.
        message: User text (may be empty for a pure card click).
        attached_gcs_uris: ``gs://`` URIs attached to the turn.
        confirmation_response: ``{"confirmationId": ..., "confirmed":
            bool}`` or ``{"confirmationId": ..., "answerText": str}``.
        operation_completed_event: Client-managed LRO completion event.
        resume_from_sequence_number: Replay from this sequence number.
        enable_confirmation_cards: Override the profile's card setting.
        enable_client_managed_lro: Advertise ``CLIENT_MANAGED_LRO``.
        timeout_seconds: Overall deadline for this stream.
        on_event: Callback for every raw JSON event.
        into: Merge the sub-stream into this aggregate instead of a new one.

    Returns:
        The events of this stream (``into`` when provided).
    """
    body: dict[str, Any] = {
        "message": message or "",
        "clientCapabilities": self._capabilities(
            enable_confirmation_cards,
            enable_client_managed_lro=enable_client_managed_lro,
        ),
    }
    if attached_gcs_uris:
        body["attachedGcsUris"] = list(attached_gcs_uris)
    if confirmation_response:
        body["confirmationResponse"] = confirmation_response
    if operation_completed_event:
        body["operationCompletedEvent"] = operation_completed_event
    if resume_from_sequence_number is not None:
        body["resumeFromSequenceNumber"] = str(resume_from_sequence_number)

    if self.rate_limiter is not None:
        self.rate_limiter.wait_and_consume()

    url = (
        f"{self._base_url}/{self.session_name(session_id)}"
        ":streamChatAiAssistant"
    )
    reducer = TurnStreamReducer(on_progress=self._progress)
    target = into if into is not None else TurnStreamEvents()
    deadline = time.monotonic() + timeout_seconds
    count = 0
    request_body = body
    reattached = 0
    handoffs = 0
    merged = False

    def _merge_once() -> None:
        nonlocal merged
        if not merged:
            target.merge(reducer.events)
            merged = True

    try:
        while True:
            seq_before = reducer.events.last_sequence_number
            reducer.events.handoff = None
            try:
                with self._stream_session.post(
                    url,
                    params={"alt": "sse"},
                    headers=self._headers(),
                    json=request_body,
                    stream=True,
                    timeout=(30, self.stream_idle_timeout),
                ) as response:
                    if response.status_code >= 400:
                        raise self._error_from_response(response)
                    for obj in iter_stream_json(response):
                        count += 1
                        reducer.feed(obj)
                        if on_event is not None:
                            on_event(obj)
                        if time.monotonic() > deadline:
                            _merge_once()
                            raise ArcStreamTimeout(
                                f"Turn exceeded {timeout_seconds:.0f}s "
                                f"deadline after {count} events.",
                                target,
                            )
                if reducer.events.turn_completed is not None:
                    break

                if (
                    reducer.events.handoff is not None
                    and handoffs < _MAX_HANDOFF_RECONNECTS
                ):
                    handoffs += 1
                    resume_seq = seq if seq is not None else 0
                    request_body = {
                        "attachOnly": True,
                        "resumeFromSequenceNumber": str(resume_seq),
                        "clientCapabilities": body["clientCapabilities"],
                    }
                    continue
                if seq is not None:
                    if seq_before is not None and seq > seq_before:
                        reattached = 0
                    if reattached < self.max_reattach_attempts:
                        reattached += 1
                        self._progress(
                            "stream closed before turnCompleted after "
                            f"{count} events; re-attaching from sequence "
                            f"{seq} (attempt {reattached})"
                        )
                        time.sleep(min(2 * reattached, 5))
                        request_body = {
                            "attachOnly": True,
                            "resumeFromSequenceNumber": str(seq),
                            "clientCapabilities": (
                                body["clientCapabilities"]
                            ),
                        }
                        continue
                    _merge_once()
                    raise ArcStreamInterrupted(
                        "Stream closed before turnCompleted after "
                        f"{count} events (last sequence {seq}).",
                        target,
                    )
                break
            except (
                requests.exceptions.ReadTimeout,
                requests.exceptions.ConnectionError,
                requests.exceptions.ChunkedEncodingError,
            ) as e:
                if reducer.events.turn_completed is not None:
                    break
                # requests surfaces a read timeout that happens *while
                # iterating* the body as ConnectionError(ReadTimeoutError).
                if _is_read_timeout(e):
                    _merge_once()
                    raise ArcStreamTimeout(
                        f"Stream idle for {self.stream_idle_timeout:.0f}s "
                        f"after {count} events.",
                        target,
                    ) from e
                seq = reducer.events.last_sequence_number
                if (
                    seq_before is not None
                    and seq is not None
                    and seq > seq_before
                ):
                    reattached = 0
                if (
                    seq is not None
                    and reattached < self.max_reattach_attempts
                ):
                    # The turn keeps running server-side; re-attach and
                    # replay from the last sequence number we saw.
                    reattached += 1
                    self._progress(
                        f"stream dropped after {count} events; "
                        f"re-attaching from sequence {seq} "
                        f"(attempt {reattached})"
                    )
                    time.sleep(min(2 * reattached, 5))
                    request_body = {
                        "attachOnly": True,
                        "resumeFromSequenceNumber": str(seq),
                        "clientCapabilities": body["clientCapabilities"],
                    }
                    continue
                _merge_once()
                raise ArcStreamInterrupted(
                    f"Stream interrupted after {count} events: {e}", target
                ) from e
    finally:
        _merge_once()
    return target

    def iter_stream_json(response: requests.Response) -> Iterator[dict[str, Any]]:
    """Yields JSON objects from a streaming REST response.

    Handles both ``?alt=sse`` (``data: {...}`` lines) and the default
    One Platform JSON-array framing (``[{...},{...}]``).
    """
    content_type = (
        response.headers.get("content-type")
        or response.headers.get("Content-Type")
        or ""
    ).lower()
    if "text/event-stream" in content_type:
        for raw in response.iter_lines(decode_unicode=False):
            if not raw or not raw.startswith(b"data:"):
                continue
            payload = raw[5:].strip()
            if not payload:
                continue
            yield json.loads(payload.decode("utf-8"))
        return

    decoder = json.JSONDecoder()
    # Chunks may split a multi-byte UTF-8 sequence; decode incrementally.
    utf8 = codecs.getincrementaldecoder("utf-8")()
    buffer = ""
    started = False
    for chunk in response.iter_content(chunk_size=8192, decode_unicode=False):
        if not chunk:
            continue
        buffer += utf8.decode(chunk)
        while True:
            buffer = buffer.lstrip()
            if not started:
                if not buffer:
                    break
                if buffer[0] == "[":
                    buffer = buffer[1:]
                started = True
                continue
            if buffer[:1] in (",", "]"):
                buffer = buffer[1:]
                continue
            if not buffer:
                break
            try:
                obj, end = decoder.raw_decode(buffer)
            except ValueError:
                break  # need more bytes
            buffer = buffer[end:]
            if isinstance(obj, dict):
                yield obj
    rest = buffer.strip().strip("],").strip()
    if rest:
        obj = json.loads(rest)
        if isinstance(obj, dict):
            yield obj

    def decide(self, cards: Sequence[CardLike]) -> list[ConfirmationAction]:
    """See base class."""
    actions = []
    for card in cards:
        if not card.confirmation_id:
            continue
        matched = False
        for rule in self._rules:
            if rule.max_uses and rule._used >= rule.max_uses:
                continue
            if not rule.filters_match(card):
                continue
            rule._seen += 1
            if rule.occurrence and rule._seen != rule.occurrence:
                continue
            rule._used += 1
            matched = True
            action = self._from_rule(rule, card)
            if action is not None:
                actions.append(action)
            break
        if not matched and self._default == "click":
            actions.extend(self._fallback.decide([card]))
    return actions

    def make_policy(
    name: str | None,
    typed_reply_probability: float | None = None,
    seed: int | None = None,
    script: Mapping[str, Any] | None = None,
    question_answerer: QuestionAnswerer | None = None,

    deny_tools: Sequence[str] = (),

    """Builds a policy from its CLI/config name.

    Args:
        name: Policy name ("manual", "click", "mixed", or "scripted"). None or
            empty defaults to "manual".
        typed_reply_probability: Probability of typing instead of clicking for
            "mixed" or "scripted" policies. None uses
            DEFAULT_TYPED_REPLY_PROBABILITY for "mixed".
        seed: Optional RNG seed for "mixed" or "scripted" policies; None picks
            a time-based seed for "mixed" or 0 for "scripted".
        script: Script configuration mapping for "scripted" policy; None uses
            an empty script.
        question_answerer: Optional callback returning an answer for question
            cards.
        answers: Optional explicit answer overrides keyed by confirmation ID
            or tool name.
        deny_tools: Optional fnmatch globs of gated tools to automatically
            decline under "click", "mixed", or "scripted" fallback.

    Returns:
        The configured ConfirmationPolicy instance.

    Raises:
        ValueError: If `name` is not a recognized policy name or the
            script/policy parameters are invalid.
    """
    key = (name or "manual").strip().lower()
    if key == "manual":
        return ManualPolicy()
    if key == "click":
        return ClickPolicy(
            question_answerer=question_answerer,
            answers=answers,
            deny_tools=deny_tools,
        )
    if key == "mixed":
        return MixedPolicy(
            typed_reply_probability=(
                DEFAULT_TYPED_REPLY_PROBABILITY
                if typed_reply_probability is None
                else typed_reply_probability
            ),
            seed=seed,
            question_answerer=question_answerer,
            answers=answers,
            deny_tools=deny_tools,
        )
    if key == "scripted":
        merged = dict(script or {})
        if (
            typed_reply_probability is not None
            and "typed_reply_probability" not in merged
        ):
            merged["typed_reply_probability"] = typed_reply_probability
        if seed is not None and "seed" not in merged:
            merged["seed"] = seed
        if answers is not None and "answers" not in merged:
            merged["answers"] = answers
        if deny_tools and "deny_tools" not in merged:
            merged["deny_tools"] = list(deny_tools)
        return ScriptedPolicy.from_dict(
            merged, question_answerer=question_answerer
        )
    raise ValueError(
        f"Unknown confirmation policy {name!r}; expected one of {POLICY_NAMES}"
    )
